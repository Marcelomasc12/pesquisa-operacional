# Pesquisa Operacional

Site educacional desenvolvido para apoiar o aprendizado da disciplina de Pesquisa Operacional e Teoria dos Jogos. Reúne explicações, exercícios e atividades interativas para ajudar os alunos a compreender e aplicar os conceitos estudados em sala.

## Funcionalidades

- **Conteúdo** — explicações sobre ponto ótimo e teoria dos grafos, acompanhadas de ilustrações.
- **Simuladores** — permitem modificar variáveis e restrições, explorar gráficos e criar cidades e estradas para estudar caminhos mínimos.
- **Exercícios** — questões com respostas comentadas e feedback.
- **Revisão** — atividades interativas para praticar a construção de fórmulas e restrições.
